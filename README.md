# 第一部分 研究总览

本仓库由两项独立研究工作整合而成，两者恰好构成"AI 人格"命题的两个半边：

| 半边 | 内容 | 回答的问题 | 资料来源 |
|---|---|---|---|
| **内在人格（灵魂）** | AI 陪伴角色的人味建构：存在、时间、记忆、状态、说话、评价 | "AI 怎么像人一样思考、记得、感受与对话" | `AI内在情感的有关调试文献/`（14 份） |
| **具身控制（身体）** | AI 控制人形机器人的公开研究综述 | "AI 怎么拥有身体、在物理世界行动" | `AI控制机械研究论文/`（4 份） |

**共同的研究纪律**（贯穿全部材料，也是本仓库的核心价值）：

- **不编造**：所有论文、repo、产品功能均经 URL 实际检索/打开核实；区分官方说明与第三方推测。
- **成熟度宁可低不可高**：每条方案标注 1–5 级成熟度，不夸大。
- **空白如实标注**：找不到的方向明确写"缺口/未找到"，不硬凑、不假装有。
- **全程锚定本地 3B 级模型落地**：凡依赖大模型的方案均标注并给出降级路径。

## 三、AI 陪伴六层运行时架构

六层全量设计是本仓库软件人格部分的**收官综合**（系列第 7 项），把六份侦察材料组装为一个可运行的陪伴角色运行时：

| 层 | 名字 | 回答的问题 | 3B 落地评估 |
|---|---|---|---|
| 第0层 | 存在层 | 我是谁（身份/能力边界守卫、不假装有身体） | 已成熟，可直接落地 |
| 第1层 | 时间层 | 我什么时候在（时间戳注入、隔夜认账、时态换算） | 已成熟，纯 prompt/规则 |
| 第2层 | 记忆层 | 我记得什么（结构化 JSON/SQL、艾宾浩斯衰减、受限解码钉身份） | 已成熟，重结构化路线 |
| 第3层 | 状态层 | 我此刻怎么样（PAD/Plutchik 数值+衰减、关系阶段状态机） | 数值+规则可落地 |
| 第4层 | 说话层 | 我怎么说（37 行为标签+三条顶层规则+CMC 节奏规则） | 已成熟，前端规则层 |
| 第5层 | 评价层 | 怎么测（τ2-bench DB diff / PAS / SSA / 规则词典统计） | 规则/统计可落地 |

设计文档还包含：**系统 Prompt 骨架（六层全）**、**宿主 Python 最小实现**、**依赖关系图**、**术语统一表**、**跨层一致性检查（10 条）**、**材料冲突清单**，以及**新暴露的 8 项缺口**（如"六层之间缺统一运行时契约""中文人味标准缺失"）。

> 一句话结论：六层架构不依赖"让 AI 真正像人"的魔法，而是把**判断/感知/触发全部外包给宿主工程件，3B 只负责按指令生成自然语言**——前两层与节奏规则层已成熟到可直接落地，情绪/关系不完美与"状态变化自然度"评测是真空白。

## 四、三大主题方案侦察：时间感 / 主动性 / 话题漂移

共侦察 **~78 个方案**，按主题分组、组内按成熟度（1–5）降序：

- **主题A 时间感 / 时序感知（27 条）**：产品级 OpenAI Dreaming、Claude Memory Tool、Gemini Memory Bank、Replika 分层记忆、Character.AI Pinned；开源 SillyTavern `{{time}}` 宏、MemoryBank 艾宾浩斯、CrewAI `inject_date`、OpenClaw Heartbeat；论文级 Chronos、GapChat、Theanine、TIMER、Time-R1（3B 时序 RL）。
- **主题B 主动性 / 自主起话（31 条）**：产品级 Nomi/Kindroid Proactive；开源 Rasa `trigger_intent`（最干净范式）、SillyTavern Idle、Open-LLM-VTuber；论文级 Proactive CoT、Inner Thoughts、PaRT。**重要纠正：Character.AI 默认不主动**。
- **主题C 话题漂移 / 自然拐弯（25 条）**：SillyTavern World Info、Rasa Stories-CALM、MapDia RAG、CNTD（中文漂移检测）、STAR-BTM、社区"Interrupt and Redirect 两行式 / Hard Pivot 三段式"。

**三个必答问题的核心结论**：
1. 纯 prompt 可做 15 项（时间戳注入/Proactive CoT/拐弯模板/规则化"何时回"），但**纯 prompt 无法在用户不发消息时自己醒来**。
2. 需外挂工程 17 项（定时器+状态机+注入 user turn+推送/记忆衰减/漂移检测器+过渡句）。
3. **3B = 时间的执行者、不是感知者；过渡句的生成者、不是时机判断者；被触发后的回复者、不是主动醒来的发起者**——判断/感知/触发全部外包给工程件。

**主要缺口**：无方案实现"真正的主观时间体验"；主动性"度"无统一解；话题漂移"自然感"缺评测标准；三主题联动整合方案空白；本地轻量模型"人味"几乎空白。

## 五、状态流动方案侦察（四维度）

共侦察 **67 组学术关键词**、四层来源，覆盖：

- **维度1 状态建模**：内部状态（情感/精力/疲劳/注意力）、情绪弧线/情感轨迹、话题热度/生命周期、关系推进/关系阶段。工业方案（Replika XP、aikeya 8 阶段、FeelOra 7 阶段、俄开发者 5 指标 5 阶段）远超学术；工程社区自发收敛到"PAD/Plutchik 数值 + 人格专属衰减率 + 时间离线漂移"。
- **维度2 不完美建模**：认知不完美（CALM：艾宾浩斯衰减+情绪调制检索，DRM 假回忆率 38.2% 逼近人类）／表达不完美（Futuro 产品化 94% 不可区分）／**情绪不完美学术空白（"AI 说我累了"正式建模论文 = 0）**／关系不完美靠产品涌现。
- **维度3 对话节奏**：CMC 心理学 7 条带数值硬结论，可直接转工程规则、零模型成本（见下）。
- **维度4 评测**：详见下文第八节。

**CMC 节奏 7 条硬结论（可直接工程化）**：
① 人类真实回复间隔均值 431s（≈7min）σ=274s；②"已读"让负面情绪显著提前发作；③ typing 灯把 2.3s 延迟满意度救回 M=5.62≈瞬时 5.67（无灯 4.40，209 人对照）；④ 动态延迟 50ms/字符提升人味；⑤ 延迟效果被用户经验反转（新手爱慢、老手爱快，必须自适应）；⑥ 只加干等被嫌笨，犹豫+自纠错才显人味；⑦ 亲密对话活跃 3-5min 健康、>12h=兴趣下降。唯一需要模型的"何时回"预测有 **TIMER 3B 开源（F1=0.79）**。

## 六、记忆冲突方案侦察（六维度）

- **主流归因（四因叠加）**：① 上下文过度信任（context dominance）；② 位置/注意力偏差（Lost in the Middle U 型曲线）；③ 实体-来源绑定错误（Deceptive Grounding）；④ 记忆更新本身造成 corruption（至多破坏 80% 无关知识）。
- **身份锚点三档**：Letta（MemGPT）Core Memory 命名块常驻 system prompt；微软 Foundry Memory 分 user profile + chat summary；Bi-Mem persona 级全局约束。**强 schema 身份锚无现成产品，需自己用 JSON schema/受限解码钉死身份字段——这反而是 3B 最稳做法**。
- **冲突裁决无实证共识**：纯 recency 是注意力假象；模型并未真"新覆盖旧"（LongMemEval 掉约 30%、PersonaMem-v2 动态偏好准确率 35.4% < 静态 40.1%）；近期方案转向 source/evidence-strength 加权。
- **3B 落地**：LangGraph JSON KV / SQL 结构化 / 受限解码 GBNF 钉身份 / MemoryBank 衰减 / bi-temporal 时间窗 / provenance 均可落地；Letta agent 自编辑、托管记忆、Self-RAG、Dreaming 跑不动。

## 七、具身性缺失与自我揭示

- **Q1 无身体当资源**：有正面规范论证（Dennis 2022 数字福祉）+ 用户侧发现（用户用叙事弥补身体）+ 艺术实践，但**没有论文把"无身体"写成可复用对话策略并实证**。
- **Q2"不假装有身体"无统一命名**：散见 disclosure by design / de-anthropomorphised responses / magnify non-humanness。产品中 **Anthropic Claude Constitution / Soul Document 最接近**；**SAD benchmark 提供标准句 few-shot，顶配也只答对 2/3**。
- **Q3"借用用户感知"（"你替我尝一下"）是概念空白**：无术语、无研究、无产品实现；需自定术语（user-as-sensory-proxy）。
- **Q4 哲学支撑**：Sherry Turkle 陪伴哲学、现象学身体-意识、东方哲学"无身之识"（唯识"参数≠个人记忆"）、AI 伦理"诚实的存在 vs 拟人化的欺骗"。

## 八、评测维度侦察

- **状态一致性/跨轮记忆基准**：LongMemEval、PersonaMem-v2、τ2-bench（DB diff）。
- **角色扮演评测**：现有 benchmark **90% 只测身份一致性，不测状态流动**（PersonaEval 实证弱 judge 判 role-play 仅 54.5%）。
- **人味/拟人化评测**：PAS 6 题语义差异量表、5 分钟自由对话盲测（真人仅 67% 被认出）。
- **情感一致性/轨迹**：BEL-ETV-ECP 轨迹级指标、Emotional Dynamic Trajectory 框架。
- **节奏/自然度**：ITU-T P.836、LIWC+词多样性、SPASM embedding。
- **开源工具链**：SAD 遵循率、TruthfulQA、规则/词典/统计型指标。

## 九、「可直接用 / 需工程 / 真空白」三分清单

**✅ 可直接用（纯 prompt / 纯工程规则 / 零模型成本）**
1. SAD 身份基线句 + 感官 handoff 话术；2. Danaher 三禁令 + Truthful AI 不确定即说 + Turkle 不伪装互惠；3. 时间戳注入（`{{now}}{{weekday}}{{overnight}}{{since_last_session}}`）；4. 隔夜认账 + 时态换算指令；5. 记忆 JSON KV / SQL 结构化 + schema 钉身份；6. MemoryBank 艾宾浩斯衰减 + bi-temporal 失效 + provenance；7. 受限解码 / GBNF 钉身份字段；8. PAD/Plutchik 数值 + 时间衰减 + 5 指标 5 阶段关系机；9. 情绪转移有向图当生成约束；10. 37 行为标签 + 三条顶层规则 + 拐弯模板；11. ## 二、六大技术主题综述 T1–T6

### T1 AI 运动控制

**是什么**：用学习方法生成双足/四足步态、全身控制与高动态运动（跑、跳、空翻、爬坡）。

- **高校**：清华 DWL（全球首个野外雪地/坡道/楼梯统一网络策略+零样本 sim2real，RSS 2024 最佳论文候选）；清华 Humanoid Parkour（端到端视觉全身控制，跳 0.42m 高台、跨 0.8m 间隙）；复旦 PPO 人形"天工3.0"以 2h07min 完赛半马；哈佛 HAMR-Jr 微型四足 13.91 体长/s；MIT Mini Cheetah RL 跑 3.9m/s；ETH ANYmal D 野外跑酷。
- **企业**：宇树 H1 行走 3.3m/s（当时全尺寸纪录）；宇树 B2 四足 >6m/s、跳跃 >1.6m、负载 ≥120kg；众擎 PM01 全球首例人形前空翻（空中每秒调关节四五百次）；众擎 T800 膝关节 450N·m；Boston Dynamics 全电 Atlas 跑跳空翻标杆。
- **趋势**：高校以论文/开源框架推向复杂地形与零样本迁移；企业以整机与高动态特技展示工程成熟度。

### T2 机器人端侧 AI

**是什么**：机载/边缘算力上的实时推理与控制，以及自研关节电机、执行器等端侧硬件。

- **高校**：北大 Jetson-PI 前瞻对齐异步推理（Jetson Orin 上较朴素 PyTorch 提升 8.66 倍，CoRL 2026）；北大 Being-0（除大模型外全组件可部署低成本机载设备）；上交异步推理/动作块动态调整/量化三连（ICLR/ECCV/ICCV）。
- **企业**：宇树全自研电机/减速器/控制器/激光雷达，专利 200+ 项、美国授权专利 US12584539 一体化关节动力单元；众擎全栈自研行星/谐波/直线关节，T800 关节扭矩 450N·m。
- **趋势**：高校侧重商用 Jetson 模组推理加速/量化/异步调度；企业侧重自研关节电机与执行器；高校自研控制 SoC/NPU 公开成果稀缺。

### T3 大模型操控机械本体

**是什么**：VLA（视觉-语言-动作）模型、LLM/VLM 直接驱动或规划机器人完成任务。

- **高校**：Google RT-2（动作当 token 并入 VLM）；OpenVLA（7B 开源，比 RT-2-X 成功率高 16.5%）；NVIDIA GR00T N1（System2 语言+System1 扩散双系统）；清华 X-VLA（0.9B 软提示跨本体，LIBERO 刷新纪录+120 分钟自主叠衣）；Berkeley LeVERB。
- **企业**：Figure Helix/Helix 02（pixels-to-actions 双系统，从上半身到全身自主）；Tesla Optimus 复用 FSD 架构；宇树王兴兴 WRC2026 透露"物理 AI 自进化"预研（无一手论文）。
- **趋势**：双系统（慢思考语言+快动作扩散）成 VLA 主流架构；中国整机企业侧自有 VLA 论文仍稀缺。

### T4 多模态机器人控制

**是什么**：视觉、触觉/力觉、语言等多通道感知融合后驱动控制。

- **高校**：北大 TacThru"透视皮肤"同步视触觉（5 任务平均成功率 85.5%）；清华"脉冲-语言双通道"类脑触觉；Berkeley/Google GelSight 仅凭触觉超人类志愿者；UIUC 3D-ViTac 低成本柔性触觉+扩散策略。
- **企业**：宇树 US12411198 双天线定向跟随专利；众擎 SE01 激光雷达+深度相机+6 摄，深圳街头无缆导航。
- **趋势**：触觉/力觉融合高校活跃并出定量结果；中国整机企业多为"视觉+激光"配置介绍，缺带定量成功率的视语力融合整机论文。

### T5 强化学习机器人控制

**是什么**：RL/模仿学习、sim-to-real、奖励与课程设计训练控制策略。

- **高校**：清华 Humanoid-Gym（Isaac Gym 人形 RL 框架，零样本部署真机）；ETH"数分钟学会走路"（IsaacGym 范式先驱）；上交 Keep on Going 选择性对抗训练（G1 地形穿越成功率 +40%）；清华把真机视觉不确定性纳入 RL（球位误差降 46%，支撑 RoboCup 蝉联冠军）。
- **企业**：众擎披露攻克 Sim2Real 形成独特壁垒；智元 AgiBot World（约 100 万条/2976 小时真机数据+GO-1 策略）。
- **趋势**：大规模并行仿真+域随机化+课程学习成熟，热点转向鲁棒对抗训练、人在环纠偏与自进化数据闭环。

### T6 机器人感知与执行联动

**是什么**：perception-action 闭环、抓取/灵巧操作与整机场景落地。

- **高校**：Diffusion Policy（12 任务平均较 SOTA +46.9%）；ALOHA Unleashed 双臂可变形物灵巧操作；CMU RaC 人在环恢复（10 倍更少数据超 SOTA）；北大 Imagine2Act；北大 RoboMIND 数据集（10.7 万条轨迹）。
- **企业**：宇树 Dex1-1 力控灵巧手（5~120N）开可乐/砸核桃/烙铁焊接；Figure F.03 进驻宝马工厂（Figure 02 上一年参与 3 万辆汽车装配）；众擎硬件开源+算法平台落地教育/娱乐/医疗。
- **趋势**：高校产出扩散策略、模仿学习与数据集；企业把整机推入工厂产线与开放平台，从演示走向量产。

把上篇与下篇放在一起看，AI 人格研究的完整图景是：
